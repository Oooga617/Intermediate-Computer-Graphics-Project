# Intermediate-Computer-Graphics-Project

This project was created for my Intermediate Computer Graphics course back in Year 2 of Ontario Tech University as a final project. I was inspired by Resident Evil a lot to try and recreate the infamous Tea Room cutscene, where your character encounters their first zombie in the game. There is a massive focus on VFX and Cinematography along with other mechanics such as tank controls, and interacting with the world through shooting, door transition, or picking up an item.
This features:
Fixed Camera Angles.
Cutscenes for the zombie, picking up an item, and a door transition (it doesn't lead any where though).
VFX (blood, outside weather effects, and muzzle flashes).

The VFX and scripting was entirely done by me, but a lot of the assets itself came from the Unity Asset store so I can focus working on the assignment requirements itself. 

If I were to go back, I would heavily refine the code and logic for the movement, shooting, interactions and cutscene triggers.
